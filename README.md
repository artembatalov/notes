### Алгоритмы: темы

Анализ сложности · Поиск и выбор · Сортировки · Линейные структуры · Кучи · Хеширование · **Контейнеры C++ (STL)** · Динамическое программирование · Графы: обходы и связность · Кратчайшие пути · Минимальные остовные деревья · Паросочетания и потоки · Строки

Контейнеры C++ показаны так, как они устроены в libstdc++ (GCC): `vector`, `deque`, `list`/`forward_list`, `map`/`set` (красно-чёрное дерево), `unordered_map`, `string` (SSO), адаптеры `stack`/`queue`/`priority_queue`. Сценарий операций редактируется прямо на странице.

| `Space` | Play / пауза |

| `R` | Сброс |
| `/` | Поиск на странице раздела |

## Устройство репозитория

```
index.html              ← хаб: список разделов
catalog.js              ← каталог разделов, тем и материалов (единственный источник навигации)
assets/
  site.css, site.js     ← хаб и страницы разделов
  viz/                  ← общий движок визуализаций
    engine.js           ← VizAnim (плеер шагов), VizGraph, VizCode, VizState
    cpp.js              ← помощники для контейнеров C++: сценарий, лента операций, память
    nav.js              ← «‹ пред. · след. ›» в шапке визуализации
    base.css
algo/
  index.html            ← страница раздела (строится из catalog.js)
  <тема>/<материал>/    ← index.html + algo.js (+ model.js)
```

### Как добавить материал или раздел

1. Положить страницу в `<раздел>/<тема>/<материал>/index.html`. Ссылки на общие файлы — `../../../assets/viz/…`.
2. Добавить запись в `catalog.js`: `{ slug, title, t }` в нужную тему.

Новый раздел — это новая папка с `index.html`, как `algo/index.html` (вызывает `NotesSite.renderSection('<id>')`), плюс объект в `NOTES.sections`. Хаб и навигация подхватят его сами.
